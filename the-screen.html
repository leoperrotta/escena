THE SCREEN

Not a scene. A surface.

THE SCREEN is not a SCENE. It is the structural center of the system — the surface where all other scenes appear.

Used alone, it is a field without figure. Neither presence nor absence: a threshold, a membrane, a condition of perception.

When layered with any SCENE, THE SCREEN does not add — it amplifies, extends, filters.

Function within the System

The membrane of the system.

Every SCENE in ROLL I is designed to function in relationship with THE SCREEN. THE SCREEN provides the ground. The SCENE provides the figure.

THE SCREEN is what remains when everything is removed. It is the silence between the scenes. The interval between cuts.

Material Elements

THE SCREEN is composed of elements that do not announce themselves. It is calibrated to disappear — to become the background against which everything else is perceived. It is not neutral. It is invisible.
