What ESCENA is

A fragrance house built through the language of cinema.

ESCENA is a conceptual perfume house built through the language of cinema. Each fragrance is conceived as a scene inside an unwritten film.

Each fragrance is a scene. Each collection is a roll. The system is a film.

The house appears gradually, scene by scene.

The System
The System

A scent is a scene.
A system is a film.

ESCENA is structured as a film studio. Each perfume is a SCENE: a constructed space composed of material elements.

The house operates in production units called ROLLS. ROLL I is the first complete chapter. Subsequent rolls extend the system.
